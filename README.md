** KALA **

Kala adalah aplikasi metode manajemen waktu berbasis pomodoro dengan tambahan pengingat deadline yang diharapkan dapat
membantu mahasiswa untuk mengatur waktu dan dapat mengumpulkan tugas dengan baik dan sempurna secara tepat waktu

** Harapan **

Harapakan kedepannya untuk aplikasi ini ada fitur pengeblokan suatu aplikasi maupun situs dalam keadaan memulai timer (fokus)

** Cara mengakses **
1. Download file dalam bentuk zip
2. Extract file dan masuk ke dalam file kala-main
3. lalu buka cmd dari folder tersebut
4. berikan perintah npm install
5. setelah npm install berhasil berikan npm install (untuk meriview aplikasi tanpa melakukan pengunduhan)
6. Jika ingin aplikasinya menetap di komputer anda, gunakan perintah npm run dist untuk membuat installer yang akan berada pada folder dist
7. Buka installer dan aplikasi siap digunakan
